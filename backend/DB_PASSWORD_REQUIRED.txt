Issue: PostgreSQL SCRAM auth failure during Spring Boot startup.

Cause: spring.datasource.password is empty.
Config: backend/src/main/resources/application.properties uses:
  spring.datasource.password=${DB_PASSWORD:}
So DB_PASSWORD must be provided.

Fix:
1) Run from d:/reactestate1/backend using PowerShell:
   $env:DB_PASSWORD="YOUR_PASSWORD"
   $env:DB_USERNAME="postgres"   (if needed)
   mvn -DskipTests spring-boot:run

2) Or set spring.datasource.password directly in application.properties for local dev.

If you want me to apply code changes, provide the preferred approach (env var vs hardcoded) and the correct DB username/password (or confirm you already have them set).
